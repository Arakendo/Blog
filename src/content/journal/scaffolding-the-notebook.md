The first Astro migration used a documentation theme. That worked technically, but it repeated the same mismatch as the old blog: it chose a presentation model before the content model was understood.

The custom scaffold now separates:

- **Ideas**, which explain the best current understanding.
- **Projects**, which provide living evidence.
- **Journal entries**, which preserve discovery and revision.
- **Atlas terms**, which connect the vocabulary.

The next work is editorial as much as technical. The structure exists so real writing can challenge it.
